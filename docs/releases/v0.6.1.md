# Telegraphica v0.6.1 — Aqua, refined

This update follows the first Aqua release with fixes from everyday use on an
older Mac. It refines the smaller windows, message details and navigation as
well as the main conversation view. Classic and Workshop remain available in
the same application.

## Choose your interface

Open **Settings → Appearance → Interface → Aqua**. In Russian:
**Настройки → Оформление → Интерфейс → Aqua**. Confirm the change to restart
Telegraphica automatically. Your saved interface choice and Classic theme are
preserved; Classic remains the default when no choice has been saved.

## What changed

- **Folders and forum topics:** returning to All Chats works after entering a
  topic through a folder. Individual topics can be marked as read; administrative
  actions follow the account's current permissions.
- **Message details:** aligned times and read receipts, corrected pin placement
  and available view counts. Group reader counts appear only when Telegram
  supplies them; unavailable values are not shown as zero. Pin and mute markers
  keep fixed columns at the right of chat rows.
- **History and window resizing:** fixed an orphaned loading spinner after forum
  discovery and layout problems when narrowing the main window or changing panels.
  The loading indicator rotates in the expected direction.
- **Attached chat search:** a compact results list opens beneath the toolbar
  search field. The duplicate sidebar search button is removed in Aqua.
- **Attachments:** removed the repeated file-information block and gave multiline
  captions a scrollable editor, with safer undo handling between attachments.
- **Profile and media:** lighter thumbnail presentation, details kept in the dark
  viewer, and a category dropdown when the full tab row would not fit.
- **Consistent Aqua windows:** refined folders, notifications, profile editing,
  privacy/storage, location sharing, reader/reaction lists, chat information and
  administration. Contacts, calls, sessions, bot commands/keyboards, QR login and
  the full download manager now share clearer spacing and control presentation.
- **Controls and icons:** restored missing menu icons, added a small set of
  MIT-licensed Phosphor assets, unified back/pin/import actions and improved
  selected-row contrast. Momentary actions return to their neutral state.
- **Context-aware actions:** Saved Messages hides audio/video calls to yourself;
  private chats no longer offer group administration.

One Intel `x86_64` application targets **OS X 10.8 through macOS 10.13**:

- [DMG installer](https://github.com/MiChiRose/telegraphica/releases/download/v0.6.1/Telegraphica-v0.6.1-macos10.8-10.13-x86_64.dmg)
- [Application ZIP](https://github.com/MiChiRose/telegraphica/releases/download/v0.6.1/Telegraphica-v0.6.1-macos10.8-10.13-x86_64.app.zip)

Quit Telegraphica before replacing the app. Keep its Application Support folder;
there is no need to remove your session or settings. Matching SHA-256 files are
provided for both downloads. The existing installer artwork is retained.

## Verification and known limits

Built with **Xcode 5.1.1** for the shared **10.8 deployment target**, using the
unchanged bundled TDLib runtimes and previously verified call transport.
Automated checks cover Classic/Aqua, both runtime-selection/capability paths,
localized layouts, message metadata, topic permissions, asynchronous ownership
and actual control/icon rendering. Final package checks cover Intel binaries,
runtime metadata, bundled resources, signatures, account-free launch, DMG/ZIP
contents and checksums.

Live Aqua checks were performed on **OS X 10.9.5 Mavericks**. Physical OS X 10.8
and macOS 10.10–10.13, a fresh login/logout cycle, real outgoing scheduled messages,
and new call/camera/microphone sessions were not revalidated for this update.
Some auxiliary flows were checked with native components and synthetic data.
Deployment-target and fallback tests do not replace physical tests of those
systems. No CPU, heat or frame-rate improvement is claimed.

**Known issue:** a draft may be missing from the composer after restarting the
application. Keep important unsent text separately before updating, restarting
or switching interfaces; draft restoration remains under investigation.

See [runtime capability limits](../tdlib-capabilities.md) and the
[TDLib update/rollback guide](../tdlib-update-and-rollback.md).
