# Telegraphica v0.6.0 — Aqua comes to Telegraphica

Aqua is a new, optional interface inspired by the metal, gloss and inset controls
of classic Mac OS X. This update keeps Classic, its existing themes, and Workshop
in the same application.

## Choose your interface

Open **Settings → Appearance → Interface → Aqua**. Confirm the change to restart
Telegraphica automatically. The same control returns you to Classic; your Classic
theme is preserved. Existing installations keep their saved interface choice;
Classic remains the default when no choice has been saved.

## What changed

- Aqua chrome, textured controls and a top navigation toolbar with tooltips.
  Settings is available in the account menu.
- An animated folder drawer beside the main window. When space permits, the main
  window moves to make room; an internal folder list remains the fallback.
- Local chat backgrounds: colors, textures, five bundled wallpapers or your own
  image. Photos fill the conversation without stretching. These settings stay
  local and do not require Telegram Premium.
- Attached sticker and download panels. Sticker search has a full-width native
  field; set removal appears only for a selected set. The full download manager
  remains available.
- A dark photo viewer with compact controls, zoom/reset, gallery navigation and
  thumbnail transitions; refined audio playback, video-note and recording views.
- Updated profile/media navigation, utility dialogs, search filters, calendar and
  scheduling presentation. **Right-click Send → Send on schedule…** to schedule a
  message; the chat's scheduled messages appear in an attached shelf.
- Better selected-row and control contrast, theme-aware original read receipts,
  aligned reaction glyphs and reactions consistently below message text.
- Muted chats no longer produce banners, sounds or a contribution to the global
  unread/Dock count. Their local gray unread marker remains visible.
- Navigation, focus, window placement and momentary-button state corrections.
  Optional motion follows the existing animation/economy settings.

## Downloads and installation

One Intel `x86_64` application targets **OS X 10.8 through macOS 10.13**:

- [DMG installer](https://github.com/MiChiRose/telegraphica/releases/download/v0.6.0/Telegraphica-v0.6.0-macos10.8-10.13-x86_64.dmg)
- [Application ZIP](https://github.com/MiChiRose/telegraphica/releases/download/v0.6.0/Telegraphica-v0.6.0-macos10.8-10.13-x86_64.app.zip)

Quit Telegraphica before replacing the app. Keep its Application Support folder;
you do not need to remove your session or settings. Matching SHA-256 files are
provided for both downloads. The existing installer artwork is retained.

## Verification and known limits

The release uses the shared 10.8 deployment target, legacy Xcode 5.1.1 toolchain,
unchanged TDLib runtimes and previously verified call transport. Automated checks
cover both runtime-selection/capability paths, Classic/Aqua presentation,
localization, layouts, cancellation and asynchronous context ownership. Package
checks cover nested Intel binaries, runtime metadata, resources, signatures,
account-free launch, DMG/ZIP contents and checksums.

Live Aqua checks were performed on **OS X 10.9.5 Mavericks**. Physical OS X 10.8,
macOS 10.10–10.13, a fresh login/logout cycle, real outgoing scheduled messages,
and new call/camera/microphone sessions were not revalidated for this update.
Deployment-target and fallback tests are supporting evidence, not physical tests
of those systems. No CPU, heat or frame-rate improvement is claimed.

**Known issue:** a draft may be missing from the composer after restarting the
application. Draft restoration across restart remains under investigation; keep
important unsent text separately before restarting or switching interfaces.

See [runtime capability limits](../tdlib-capabilities.md) and the
[TDLib update/rollback guide](../tdlib-update-and-rollback.md).
